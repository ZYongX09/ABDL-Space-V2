## 功能

`/admin/app-clients` 的独立提醒卡片总开关默认关闭；指定内部 versionCode，自定义纯文本或留空使用默认文案。独立复选框「包含未上报有效版本号的 App」默认勾选、始终可见，包括版本号缺失或格式无效，但仅限已经识别为原生 App 的请求，网页不受影响。总开关启用时，空版本列表且该项为 true 仍会提醒未上报有效版本号的 App；已知版本的列表匹配独立，不因该项为 false 被取消。总开关关闭时任何提醒都不生效，且保留版本、未上报选项和文案；恢复默认仅清空文案草稿。
后端契约使用现有 site_settings 的 app_client_reminder；专用 GET/PUT 保存四字段 `{ enabled, version_codes, message, include_unversioned }`，不需要新增数据库迁移。前端兼容旧三字段响应/配置：缺少新字段默认 true；显式 false 保留，显式非布尔值拒绝、不转换。所有提醒写入始终带四字段。原版本废弃四字段不变，若同时命中则废弃优先。本轮同步实现后端与前端；后端基线 main@a7dd390，新增无版本号匹配及兼容校验，未修改 Android。

提醒的后端契约是在成功、非空、无分页/增量游标的原生 App 时间线首位插入，保留全部真实帖子与原分页 Link。网页、未匹配的已知版本、include_unversioned=false 的未上报有效版本请求、错误响应、翻页/补拉与空结束页不插入。首次加载限定用于避免旧 Android 客户端重复假帖、分页死循环和补拉重叠误判；带旧游标的客户端刷新无法被后端可靠识别为首次加载。
